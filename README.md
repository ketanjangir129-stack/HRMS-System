# HRS System

**HRS System** is a modern **Human Resource Management System (HRMS)** designed to simplify and centralize day-to-day HR operations.

It provides a complete platform for managing the employee lifecycle, from employee management and attendance to leave, payroll, resignation, and full & final settlement.

### ✨ Key Features

* 👥 **Employee Management** — Manage employee profiles, departments, designations, and roles.
* 🕒 **Attendance Management** — Track punch-in/out, working hours, attendance status, and approvals.
* 🌴 **Leave Management** — Apply, approve, reject, and manage employee leaves.
* 📅 **Holiday Management** — Manage company holidays and integrate them with attendance and leave.
* 💰 **Payroll & Payslips** — Manage salary information and provide employees with downloadable payslips.
* 📝 **Resignation Management** — Employee resignation workflow with manager and HR approvals.
* 💼 **Full & Final Settlement** — Manage the employee exit and final settlement process.
* ✅ **Task Management** — Create, assign, track, and manage employee tasks and their progress.
* 🔐 **Role-Based Access** — Different access and permissions for Owners, HR, Managers, and Employees.
* 🏢 **Multi-Company Support** — Company-level data isolation and scalable API architecture.

### 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS
**Backend:** Express.js, REST APIs
**Database:** Firebase Realtime Database
**Authentication:** Firebase Authentication

### 🎯 Project Goal

The goal of HRS System is to replace manual HR processes with a **centralized, secure, scalable, and easy-to-use HR platform** that can support organizations throughout the complete employee lifecycle.
